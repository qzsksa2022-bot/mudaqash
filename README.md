# 🃏 مداقش أونلاين

تطبيق ويب للعب مداقش مع الأصدقاء، كل واحد من جهازه (جوال أو كمبيوتر)، عبر رابط واحد وكود غرفة.

## فكرة اللعبة (كما تم تطبيقها هنا)

- كل لاعب يبدأ برصيد معيّن (تحدده عند إنشاء الغرفة).
- كل جولة توزع 4 أوراق لكل لاعب من دستة كاملة (من 2 إلى الآس).
- **المراهنة:** كل لاعب بدوره إما يرفع الرهان، أو يجاري (يدفع نفس أعلى رهان)، أو ينسحب.
- إذا انسحب الكل إلا واحد، يفوز بالبنك مباشرة بدون كشف أوراقه.
- إذا بقي أكثر من لاعب، آخر من رفع يصبح **"الشيخ" 👑**.
- **المفاوضة:** الشيخ عنده 3 محاولات يعرض فيها مبلغ على أي لاعب متبقٍ مقابل انسحابه بدون كشف أوراقه، أو يقدر يعلن **"المداقش"** (كشف الأوراق) مباشرة في أي وقت.
- **المداقش:** يكشف كل اللاعبين المتبقين أوراقهم، وصاحب أقوى مشروع يأخذ البنك كامل (وعند التعادل يتقاسمونه).
- ترتيب المشاريع من الأقوى للأضعف: رباعية ← تتابع ← ثلاثية ← زوجين ← زوج ← ورقة عالية.
- اللاعب الذي ينتهي رصيده يخرج من اللعبة. آخر لاعب يبقى معه رصيد هو الفائز الكبير 🏆.

> ملاحظة: قواعد "مداقش" الأصلية تختلف شوي بين مجموعة وأخرى (خصوصًا تفاصيل عدد الأوراق حسب عدد اللاعبين ونظام "السوم"). طبّقت هنا نسخة واضحة وقابلة للعب رقميًا بشكل متكامل. إذا تبي تعديل أي قاعدة (مثلاً عدد محاولات المفاوضة، الحد الأدنى للرفع، أو طريقة توزيع الأوراق)، قلّي وأعدلها.

## تشغيل التطبيق

يحتاج [Node.js](https://nodejs.org) (نسخة 18 أو أحدث).

```bash
npm install
npm start
```

بعدها افتح المتصفح على: `http://localhost:3000`

هذا يشغّل السيرفر على جهازك فقط — يعني تقدر تلعب من نفس الجهاز أو من أجهزة على نفس الشبكة (الواي فاي) عن طريق IP جهازك بدل localhost، مثلاً: `http://192.168.1.5:3000`.

## عشان يلعب أصدقاؤك من أي مكان (كل واحد من جهازه عبر الإنترنت)

لازم تنشر السيرفر على خدمة استضافة تشتغل 24 ساعة، عشان يصير عندك رابط ثابت يقدر يوصله أي شخص. أسهل خيارات مجانية:

### الخيار 1: Render.com (الأسهل)

1. ارفع هذا المشروع على GitHub (حساب مجاني).
2. روح [render.com](https://render.com) وسجّل حساب مجاني.
3. اختر **New → Web Service** واربطه بمستودع GitHub.
4. الإعدادات: **Build Command:** `npm install` — **Start Command:** `npm start`.
5. بعد الإنشاء بيعطيك رابط عام مثل `https://mudaqash.onrender.com` — شاركه مع أصدقائك.

### الخيار 2: Railway.app

نفس الفكرة: ترفع المشروع GitHub، تربطه بـ Railway، يشتغل تلقائيًا لأنه يتعرف على `package.json` و`npm start`.

### الخيار 3: تجربة سريعة الآن بدون نشر (ngrok)

إذا تبي تجربة سريعة اليوم بدون ما تسوي حساب استضافة:

```bash
npm install
npm start
```

وفي نافذة طرفية ثانية:

```bash
npx ngrok http 3000
```

بيعطيك رابط مؤقت (مثل `https://xxxx.ngrok-free.app`) شاركه مع أصدقائك مباشرة — يشتغل طول ما جهازك شغّال والسيرفر يعمل، لكنه رابط مؤقت يتغير كل مرة تشغّله.

## هيكلة المشروع

```
mudaqash/
  server.js       # سيرفر Express + Socket.io وإدارة الغرف
  game.js         # منطق اللعبة (المراهنة، المفاوضة، تقييم الأوراق)
  public/         # واجهة اللعب (HTML/CSS/JS)
  test/           # اختبارات آلية (محاكاة لاعبين + اختبار متصفح)
```

## اختبار سريع للتأكد إن كل شيء شغّال

```bash
npm start &
node test/sim.js
node test/sim2.js
```

كل الاختبارات تتأكد إن مجموع أرصدة اللاعبين يبقى ثابت بعد كل جولة (يعني ما فيه "تسريب" فلوس بالخطأ في منطق اللعبة).
